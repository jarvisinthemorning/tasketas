# Legacy Battlegrounds Guides

These guides were removed from the active Tasketas catalogue on 2026-08-11 after the guide format and discovery criteria were clarified.

They are preserved as **source and evidence archives**, not current recommendations. They are intentionally excluded from `data/registry.json` and the public active index.

## Review policy

Review legacy guides only when processing the closest current HSReplay Meta composition. Classify each legacy guide as one of:

- **Same-guide update** — merge useful evidence or explanation into the canonical Meta guide.
- **Variation package** — same Commit and Core; add the changed support/payoff/trinket package to the Meta guide.
- **Related guide** — shared Commit or bridge, but materially different Core, resource engine, sequencing, positioning, or failure modes.
- **High roller** — hero-, trinket-, Dark Gift-, or narrow-combination-dependent curiosity.
- **Reject** — stale, illegal, duplicate, insufficiently evidenced, or not strategically useful.

Never republish a legacy file unchanged. Revalidate every card and strategic claim against the current card catalogue and public sources first.
